Data

The dataset is available in CSV and JSON formats. Each row describes one instrument; links to other instruments refer to their ids, so amendment chains can be followed in either direction.

CSV

rules.csv

{{ n_rules }} rules. List fields are separated by semicolons. Includes the derived amended_by and revoked_by columns.

 CSV

sources.csv

The source registry used in the search protocol: each portal's tier, languages and last observed access status.

 JSON

rules.json

The same rules with lists as arrays, plus topics, countries and allowed values.

Before you use it: check each row's verification and status_checked fields. Unverified rows were drafted from secondary sources and have not yet been checked against the official text. The data is updated by commits to data/rules.csv, so the commit history is the full change log.
